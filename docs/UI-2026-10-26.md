# 画面コメントへの対応（2026-10-26）

## 変更内容

- Decks・CardsのBlack文字を黒塗りだけに変更。以前の白い縁取りと文字影を廃止。背景と選択状態は他の色と同じ既存ルールを維持。
- 実際に表示している印刷版のセットを画像へ付与し、Alpha（LEA）には通常版より丸い角のクリップを適用。通常版の印刷枠・名前・本文を削る一律拡大はしない。画像失敗による代替版への切替時もセット情報を更新する。
- ブラウザ標準のdatalist候補をページ内の候補リストに置換。Card Name、DecksのIncluded Cards、Deck / Player / Eventの候補に01 BRASS RAILを適用。日本語・英語の部分一致、NFKC、重複除去、最大60候補、矢印・Enter・Esc・Tab、ポインター選択、IME入力を扱う。
- 検索欄の入力を候補から強制選択することはしない。候補未選択のEnterは従来の検索／追加操作へ渡す。

## 修正用CSVの出力

掲載中の48デッキを出力。元の掲載情報はまだ変更していない。

- 掲載情報CSV：全48件。大会名・会場・入賞・デッキ名・公開プレイヤー名・色・アーキタイプ・代表カード・英語リスト全文・元のメイン／サイドJSON・日時・出典・元データJSONなど、元デッキの全項目を保持。修正指示欄を追加。
- カード明細CSV：メイン／サイドを区別し、区分内の順番、枚数、日本語名、英語名、Oracle IDを出力。1,247行・計3,605枚。修正指示欄を追加。
- UTF-8 BOM、CRLF、引用符付きCSV。元データJSON、英語リスト、全カードID・枚数・順番をCSVから読み戻して一致を確認。
- デッキID・Oracle IDと照合用元データは維持し、掲載情報やカード明細を修正して返してもらう。CSVを受け取った後の反映はIDを照合して行う。CSVファイル自体は公開サイトへ置かない。

## 確認

ローカルの実ブラウザで、候補リスト内のスクロールバーの真鍮グラデーション、矢印・Enterでの候補選択、検索、Alpha版の稲妻（EN LEA #161）の画像読込と角のクリップを確認。カード名や本文は保持されている。Blackの計算済み色は黒、文字影なし。

検索候補の一致処理は `autocomplete.test.mjs` に追加。従来の検索・印刷版検証、公開ファイル検査、JS構文検査も実行する。Android／iPhone実機の確認はこの記録に含めない。
