# ビジュアルデッキ・表示版・直近入賞（2026-10-28）

- 掲載デッキ詳細の代表画像を廃止し、全カードを画像・枚数・名前のビジュアル一覧へ統一。メインは呪文／土地、サイドは分類なし。元リストの構成と枚数は維持。
- 詳細の操作を同じ44pxの行へ配置。BACKは左、Copy・Download・CLOSE×は右。カード詳細ではBACKとCLOSE×を表示し、戻る履歴・スクロール復元を維持。
- CardsのList上部の言語・セット略号・番号を廃止。セット略号を英語名の右へ移動し、タイプ行はタイプのみ。画像失敗時の代替版でもセット略号を更新。小画面の画像と日本語名の上端を統一。
- 検索画面からPrintingボタンを削除。表示版は右上Settingsで設定。
- 日本語版の対象を、最初にモダンへ導入された発売セットから選ぶ方式へ変更。8ED以降のcore/expansion、およびTSB・MH1/2/3・LTR・ACRを対象にし、Masters・統率者・ボーナスシートは導入セットとして扱わない。[公式Modern発売セット一覧](https://magic.wizards.com/en/formats/modern)を基準とする。
- 同じカードの英日メタデータから対象セットを先に決定し、そのセットの日本語通常・非FOILを優先する。対象日本語画像がなければ同セット英語、さらに同じカードの別版へ緩和し理由を表示。対象日本語版が存在しない場合も理由を表示。英語初版の優先処理は維持。
- 2026-10-24に完全取得済みの19,983印刷版メタデータから1,015カードの規則v3を再生成。画像ファイルは保存しない。稲妻の対象はM10、対抗呪文はMH2。
- Eventsの大会結果見出し・空の通算成績案内・全大会一覧を廃止。「直近の入賞リスト」で掲載順の先頭5デッキを表示する。開催日が未確認のため更新日時を開催日として推測せず、全掲載デッキはDecksで閲覧できる。
- ヘッダー右上を `rev.<Git履歴の件数> · <コミット短縮ID>` に変更。公開時に完全な履歴から生成する。手動の版番号更新は不要。

## 確認

ローカル実ブラウザーで、代表画像なし・23カード種のビジュアル一覧・表の廃止、同じ高さの操作列、画像からカード詳細への移動とBACKによる復元、Copy操作、SettingsからのJA M10選択、Listの余分なメタ情報削除、Eventsの5件を確認。小画面では画像と名前の上端一致、デッキ画像2列、モーダル横はみ出しなしを確認した。

印刷版生成の検証では対象セットの先決定、対象セットの日本語欠落時に同セット英語を保持、非導入セットの除外を検証。1,015カード全件に画像候補があること、英語初版と非FOIL優先、緩和理由、Events件数・掲載順を検証。既存の掲載データ・検索・日本語名・候補・編集ツール・公開ファイル検査も実行。
