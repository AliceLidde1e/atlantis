## デッキ編集

- 保存済み一覧 → 表示モーダル → Edit Deck → Cardsと共通の編集画面。
- 幅1100px以上ではカード検索の右に編集パネルを表示。狭い画面は同じパネルをモーダルとして開閉する。
- MAIN／SIDE／MAYBEで同名カードを区分別に保持。検索結果とカード詳細から各区分へ追加できる。
- 1枚の移動はMain→S、Side←M、Main／Side→?、Maybe←M／←S。枚数変更・直接入力・区分内削除・取り消しを実装。
- Maybeは対戦用のMO出力へ含めない。表示モーダルでは折りたたみの候補欄に表示する。
- Text / Pasteから従来の自由記述編集・クリップボード貼付を利用可能。カード操作で関係のない自由記述や区分を消さない。

## 保存・互換

- 通常のMy Decksと下書きはIndexedDBの`atlantis.my-decks.v1`へ保存。保存済みデッキと下書きは別ストア。
- 旧`atlantis.functional.mydecks.v1`のlocalStorageを初回に取り込み、元キーを削除しない。旧MO画面との互換コピーとして更新する。
- 旧MO画面の別IndexedDBは維持し、そのコピー機能から追加されたデッキを統合一覧へ読み込める。古い互換コピーを理由に正本を全削除しない。
- 旧セッションのMy StorageはRestoreで独立した下書きへ移す。引き継ぎ先の書込み成功後に元の一時データを除去する。
- 下書きはデッキ・タブごとに退避し、再読込・別タブでも復元可能。別のデッキへ切り替えても退避内容を残す。
- IndexedDBのリビジョンと既存の互換コピーを照合し、別タブの保存を古い内容で上書きする操作を拒否する。競合時は入力を保持し、Reload Decks／Save as Newを利用する。
- JSONバックアップは従来のversion 2形式を維持。Maybeは本文のMaybeboard区分として往復する。全件バックアップは未保存の下書きも「（下書き）」という別デッキとして含め、読込み時も既存デッキへ自動混入せず追加する。
- version 1・2の旧バックアップを引き続き読める。Maybeのない本文は候補なしとして扱う。
