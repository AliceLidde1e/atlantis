GitHub PagesのURLは誰でも閲覧できる。`noindex` はアクセス制限ではない。テスト用であっても、個人データ・非公開の原稿・作業用JSONを配信対象へ含めない。

正式公開を決めた際は、テスト版表示・検索エンジン方針・案内文を整合させ、公開URLを未ログイン状態と実機で確認する。既存のブラウザ内保存データを消す操作は行わない。
