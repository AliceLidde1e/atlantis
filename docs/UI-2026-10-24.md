# ATLANTIS 画面改善の確認記録（2026-10-24）

## 反映内容

- 詳細モーダルの閉じるボタン用の帯を廃止し、コンテンツを上に詰めた。Settings・Menuを含むモーダル操作ボタンの文字色・背景・枠・フォントを共通化。
- 詳細間の履歴を保持し、BACKとブラウザの戻るで前のデッキ・スクロール位置・My Decksの表示形式へ復帰。CLOSE×では詳細を開いた元のページへ戻る。
- Cardsの詳細フィルターを常時表示。PCは左側の追従サイドバー、狭い画面は検索結果より上の通常フロー。検索方法は補足説明として分離。
- 結果の上部にもページ送りを追加し、下部と同期。Displayをプルダウンに変更し、切替時と再読込時にページ位置を保持。
- Decks・CardsのBlackを共通背景にし、文字だけ黒塗り・白い縁取り。
- ホーム紹介文を指定文に変更。英語コピーは **Known Cards. Unknown Horizons.**。
- 既存の大会結果付きデッキ48件とカード1,015種類、データ形式・保存先を維持。
