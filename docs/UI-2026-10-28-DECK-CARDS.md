# デッキカードと関連デッキの仕上げ（2026-10-28）

- Home／Decksのデッキカード上部の小見出しを英語化。掲載中の22種類のアーキタイプに対応。元の日本語デッキ名・検索条件・掲載データは維持。
- 掲載デッキ詳細の「実MTGOへの取込は未検証です。」を削除。
- Decks／CardsのBlack文字を黒塗り・白い縁取りへ復元。チェックボックスには文字装飾を適用しない。
- カード詳細の関連デッキにプレイヤー名と開催日を追加。確認済みheldOnのみ日付を表示し、未登録は「開催日未登録」と表示する。記録日時・更新日時を流用しない。
- Eventsの直近5デッキに、代表カードのart_crop画像を右側へ追加。枠に合わせてobject-fit:coverでトリミング。画像から該当デッキ詳細を開ける。スマートフォン幅では情報と画像を縦に並べる。
- Home／Decks／My Decksで共通の枠を使用。画像領域、英語小見出し、日本語タイトル、情報欄の高さを揃え、タイトルは2行までとする。My Decksの操作ボタンは維持。

## 検証

英語対応表が掲載48件すべてを網羅し、英語ラベルに日本語が残らないことを検証。Eventsの画像付き表示とエスケープを検証。検索・掲載データ・印刷版・公開ファイル検査も通過。

ローカルの実ブラウザーで、PCの全48枠が327px、スマートフォン幅で全枠が195pxに揃い、情報欄の内部はみ出しがないことを確認。関連デッキのプレイヤー名・未登録表示、注意文削除、Eventsの5画像の読込とcover、画像からデッキ詳細への移動も確認した。
