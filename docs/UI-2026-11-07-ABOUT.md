# 旧MO画面の廃止とABOUT更新

更新日：2026-11-07（日本時間）

## 変更

- mo-storage.html、mo-theme.css、site-bridge.mjs、site-bridge-ui.mjsを削除。ABOUTとMenuの旧導線、旧My Storageの復元案内・復元処理・未使用の旧プール処理も削除。
- 現行My Decksは同じIndexedDB名とstate／draftsを維持。旧localStorageからの移行・併合・互換コピーを廃止。旧保存領域の削除処理は追加していない。
- 保存競合はIndexedDBのrevisionで照合。別タブの更新通知はBroadcastChannelを利用し、利用できない環境でもrevision照合で上書きを防ぐ。
- ABOUTを採用文へ置換し、公式ファンコンテンツ・ポリシーへのリンク、ブラウザ内保存、自動移行なし、通信とオフライン検索、公開URLの注意を掲載。
- 配信許可リストとActionsから廃止資産を除外。現在のREADME・要件・残タスクも更新。

## 自動検査

Check ATLANTIS siteワークフローと同じ全21項目が成功。廃止した2モジュールの構文検査を除外し、配信許可リストで旧4ファイルと旧導線が復活しないことを検査する。

## ブラウザ確認

- 隔離した一時IndexedDBで、既存デッキと下書き、旧recordのrawフィールドを持つデータの維持、別タブの古いrevisionでの保存拒否、再読込後の最新状態、新規保存の再起動後の維持を確認。全6項目成功。一時DBは検証後に削除。
- 現行エディターから1枚ずつMain／Side／Maybeへ追加して保存。保存完了を待って再読込し、My DecksとText表示で3区分の内容を確認。
- ABOUTのPC表示と390pxのCSS画面幅で横はみ出しなし。モバイルMenuにHome／Getting Started／Aboutのみが残ることを確認。
- 通常のバックアップ・枚数変更・区分移動は既存テストでも検証する。Android／iPhone実機は今回の検証に含めない。
