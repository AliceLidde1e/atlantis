- DecksとCardsに共通の検索パネルを適用。PCでは左側に固定し、検索語・色・OR/Exact・Sort・採用カード・サイド採用・アーキタイプ・Resetを常時表示。件数と結果は右側へ配置する。小画面では条件から結果へ縦に並べ、パネル内部のスクロールを解除する。説明は「検索方法」へ分離。
