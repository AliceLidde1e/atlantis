# ガイド・カード詳細・保存欄の改善（2026-10-28）

- Getting Startedに旧枠《島》のart_cropイラストを追加。Decks／Cards／My Decksの各ボックスを英語名＋日本語の案内見出しと、指定された本文へ変更。
- カード詳細は日本語名 / English nameを同じ見出しに配置。英語サブタイプを上部へ表示し、存在しない場合は欄自体を非表示。以前の和訳付きサブタイプ行・マナコスト／総量行・Printing説明・下部の重複リンクを廃止。
- 上部リンクはリンク先を維持して「Scryfallで見る」に変更。
- Main／Sideboard追加・My StorageボタンをCLOSE×と同じ44pxの操作行へ移動。スマートフォンでは短い表示名を使用し、完全な操作名はARIAラベルで保持。BACKも同じ行で左寄せ。
- Card TypeのPlaneswalker選択肢を廃止。CardsはMana Value、Decks／My DecksはRecently UpdatedをSort選択肢の先頭に配置。選択値の復元と検索ロジックは維持。
- My Storageはユーザー承認の「一覧内で保存欄を開閉する方式」を実装。通常はカード一覧を全幅表示。Saveで保存先・名前・プレビューと保存ボタンを展開し、Hide Saveで閉じる。閉じても入力・カード・枚数は保持。保存処理そのものは従来どおり。
- Copy成功時はボタンをCopied ✓へ一時変更し、モーダル内のrole=statusにもコピー完了を表示。失敗時もモーダル内に案内を表示。別の詳細へ移動した後は古い非同期処理で画面を上書きしない。

## 検証

ローカル実ブラウザーで旧枠イラストの読込、指定文言、Planeswalkerの除外、Sort順を確認。サブタイプのないアダーカー荒原では上部欄なし、稲妻の天使ではAngelを表示し、日英併記とリンク・不要行削除を確認した。

MainとSideboardに1枚ずつ追加し、保存欄へ名前を入力後に閉じて再展開しても、名前・枚数・プレビューが維持されることを確認。テスト用デッキの保存も成功。

Copyを実行してCopied ✓と完了メッセージを確認。390px幅でBACK・Main +・Side +・Storage・CLOSE×の上端と44px高さが一致し、モーダルの横はみ出しがないことを確認。公開ファイル検査、掲載データ、印刷版、検索、デッキ分類とJS構文検査も通過。
