# EVENTSカードと全件一覧

実装・表示検証：2026-11-06／最終確認：2026-11-07（日本時間）

## 変更内容

- 大会結果の枠をDECKSと揃え、優勝デッキの代表カード、大会名、開催日、会場、参加人数、優勝者、デッキ名を表示。
- 優勝が確認できない大会には共通ロゴを使う。正式結果に優勝者名だけがある場合は名前を表示し、デッキ未掲載を区別する。
- EVENTSは大会案内・大会結果それぞれ先頭6件。MOREは全件一覧へ遷移し、6件以下では非表示。
- 全件一覧は #events/results と #events/announcements。既存の大会別URLとデッキ詳細モーダルは維持。
- PCは3列、タブレットは2列、モバイル幅は1列・画像と説明の左右配置。長い大会名も表示する。
- 代表カードは既存の画像表示処理を共用し、サイト全体の表示版設定を反映。
